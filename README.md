# AI & ML Internship - Task 2: Feature Engineering, Model Optimization & Performance Comparison

## 📋 Project Overview
This repository contains the implementation for **Task 2** of the Artificial Intelligence & Machine Learning Internship at **MAINCRAFTS Technology**. 

The objective of this task is to look beyond basic machine learning models and implement an industry-aligned pipeline. Using the **California Housing Dataset**, this project demonstrates data preprocessing (Feature Scaling), training multiple regression models, and conducting an objective evaluation to select the optimal predictive model.

---

## 🚀 Key Learning Objectives
* **Data Preprocessing:** Applying `StandardScaler` to bring features onto a common scale to improve learning stability.
* **Model Optimization:** Implementing multiple regression algorithms (Linear, Regularized, and Tree-based).
* **Model Evaluation:** Analyzing performance variations quantitatively using **RMSE** and **R² Score** metrics.
* **Technical Justification:** Making deployment decisions based purely on measurable data.

---

## 🛠️ Tech Stack & Libraries Used
* **Language:** Python
* **Environment:** Google Colab / Jupyter Notebook 
* **Data Manipulation:** pandas, NumPy
* **Machine Learning:** scikit-learn
* **Data Visualization:** matplotlib
